## 8. BROKEN WIKI LINKS — 400+ Broken References

The brain files use Obsidian-style `[[wikilinks]]` but **400+ links are broken**. This is the single biggest source of AI hallucination risk.

### Root Causes
1. **Missing `.md` extension** — Links like `[[brain/SOUL]]` work in Obsidian but the file is `brain/SOUL.md`. The checker found these as "broken" but they may resolve in Obsidian. However, AI agents don't have Obsidian's link resolution.
2. **Referenced files don't exist** — Skills like `skills/task-routing/SKILL` don't exist (the skill is `skills/task-routing/` but the file is `SKILL.md`).
3. **Cross-repo references** — Links to `../CMO-Agent/brain/CONTENT_BIBLE`, `../CMO-Agent/skills/competitive-intelligence/SKILL` assume sibling repos are accessible.
4. **Deleted files** — Links to `memory/feedback_objection_handling`, `memory/feedback_outreach_signature`, `memory/feedback_power_dynamics` — these feedback files were moved or renamed.
5. **Non-existent agents** — Links to `agents/architect`, `agents/writer`, `agents/reviewer`, etc. — the `agents/` directory exists but these specific agent files may not.
