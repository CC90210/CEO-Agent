⌨️ Slash Commands — Your AI Control Panel

Slash commands are built-in shortcuts that trigger specific behaviors inside Claude Code. Instead of typing long instructions, you type /command and Claude knows exactly what to do. Think of them as keyboard shortcuts for your AI employee — except each one activates an entire workflow.

🧭 Navigation & Session Commands

These commands control your Claude Code session itself:

🆘 /help — Show all available commands. Your cheat sheet. Run this first in any new session to see what's available.

🧹 /clear — Wipe the conversation and start fresh. Use when Claude is confused or you're switching to a completely different task. Your files are safe — only the conversation resets.

📦 /compact — Compress context to save memory. This is your most important command. When Claude starts losing track of earlier instructions or repeating itself, /compact summarizes everything and frees up space. No information lost — just compressed.

💰 /cost — Show token usage and cost for this session. Keep an eye on spend. A typical session runs $0.50-$3.00 depending on complexity.

⚡ QUICK WIN: Open Claude Code right now and type /help. Count how many commands are available. You'll be surprised.

⚙️ Configuration Commands

These control how Claude Code behaves:

⚙️ /config — View and change settings. Model selection, theme, behavior preferences. This is your cockpit.

🔐 /permissions — Manage tool permissions and trust levels. Control what Claude can do without asking:

• Default — Asks before every action (training wheels)

• Auto-accept edits — Auto-approves file changes, still asks for shell commands

• YOLO — Approves everything (use only with git commits as backup)

🩺 /doctor — Health check your installation. Run this if something feels broken. It checks your environment, dependencies, and configuration.

💡 PRO TIP: Start every new project with /doctor to make sure your environment is clean. It catches problems before they waste your time.

🔄 Workflow Commands

These trigger multi-step workflows:

🔁 /loop — Run a prompt on a recurring interval. Example: /loop 5m check build status runs every 5 minutes. Perfect for monitoring deployments or watching for changes.

⏸️ /resume — Resume a previous session. Claude Code can pick up where you left off, even across terminal restarts.

🧠 KEY TAKEAWAY: Slash commands aren't just shortcuts — they're workflow multipliers. A developer who uses /compact, /cost, and /permissions effectively will outperform one who just types prompts. Master the controls before you try to fly.
