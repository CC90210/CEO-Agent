📧 Part 1: email_engine.py

Gmail SMTP. No third-party ESP. No monthly fee. Your emails go out through your own Google account, which means your domain reputation is tied to your sending habits — which is exactly how it should be.

Gmail App Password Setup

You cannot use your regular Gmail password here. Google requires an App Password for programmatic access.

1. Go to myaccount.google.com

2. Security → 2-Step Verification (must be enabled first)

3. Security → App passwords → Select app: Mail → Select device: Other → name it "email_engine"

4. Google gives you a 16-character password. Copy it immediately — it is shown once.

Add these to .env.agents:

GMAIL_USER=your@gmail.com

GMAIL_APP_PASSWORD=xxxx xxxx xxxx xxxx

⚠️ WARNING: This is your real Gmail account. Sending spam or high-volume cold outreach through it will get the account flagged. Use this for nurture sequences to warm leads, client updates, and booking confirmations — not bulk cold outreach to scraped lists.

Commands

send — Send a single email

python scripts/email_engine.py send --to "client@example.com" --subject "Your onboarding pack" --body "Hi Sarah, ..."

send-template — Send using a saved template

python scripts/email_engine.py send-template --template oasis-welcome --to "client@example.com" --vars '{"name":"Sarah","company":"Acme"}'

templates create — Save a new template

python scripts/email_engine.py templates create --name oasis-welcome --subject "Welcome to OASIS" --file templates/oasis-welcome.txt

templates list — List saved templates

python scripts/email_engine.py templates list

sequence create — Define a drip sequence

python scripts/email_engine.py sequence create --name oasis-nurture --emails '[{"delay_days":0,"template":"oasis-day0"},{"delay_days":3,"template":"oasis-day3"},{"delay_days":7,"template":"oasis-day7"}]'

sequence run — Enroll a contact in a sequence

python scripts/email_engine.py sequence run --name oasis-nurture --to "lead@example.com"

log — Show email send history for a contact

python scripts/email_engine.py log --email "lead@example.com"

stats — Open rates, click rates, sequence performance

python scripts/email_engine.py stats

The 3-Email OASIS Nurture Sequence

This is the exact sequence we run for new OASIS leads. Adapt it for your business:

Day 0 — The Value Drop

Subject: What we built for [company] in 45 minutes

Body: One specific result. No pitch. Just proof. Link to a case study or Loom walkthrough.

Day 3 — The Education Email

Subject: The $47K problem most [industry] businesses ignore

Body: Explain the cost of their current manual process. Position AI automation as the obvious fix. Soft CTA: "Does this sound like your situation?"

Day 7 — The Offer

Subject: One thing I'd fix in your business this week

Body: Specific offer. Clear ask. Book a 20-minute call. Direct link to your booking engine.

💡 PRO TIP: Templates use {{variable}} syntax for personalization. Always include at minimum {{name}} and {{company}}. Personalized subject lines consistently outperform generic ones. The send-template command handles variable substitution at send time.

📅 Part 2: booking_engine.py

Self-hosted scheduling. No Calendly. No third-party calendar sync. You open slots, leads book them, confirmations go out automatically with a .ics calendar invite attached.

Commands

slots open — Open a specific time slot for booking

python scripts/booking_engine.py slots open --date "2026-03-25" --time "14:00" --duration 30 --type "discovery"

slots open-week — Open a full week of slots at once

python scripts/booking_engine.py slots open-week --start "2026-03-24" --days "Mon,Wed,Fri" --times "10:00,14:00,16:00" --duration 30

slots list — Show all open slots

python scripts/booking_engine.py slots list

slots close — Remove an available slot

python scripts/booking_engine.py slots close --id 15

book — Book a slot for a contact (or they book via your booking page)

python scripts/booking_engine.py book --slot-id 15 --name "Sarah Chen" --email "s@acme.com"

cancel — Cancel a booking and reopen the slot

python scripts/booking_engine.py cancel --booking-id 8 --reason "Lead rescheduled"

remind — Send reminder emails for upcoming bookings

python scripts/booking_engine.py remind --hours 24

complete — Mark a booking as completed and trigger lead stage update

python scripts/booking_engine.py complete --booking-id 8 --notes "Good call, sending proposal"

How .ics Invites Work

When a booking is confirmed, the engine generates a .ics calendar file on the fly and attaches it to the confirmation email. The invite includes:

• Meeting title and duration

• A Google Meet link (generated via the Google Meet URL format)

• Your contact details as the organiser

• A reminder 15 minutes before

The lead clicks "Accept" in their email client and the meeting lands on their calendar. No integration, no OAuth, no API key. Just a text file formatted to the iCalendar spec.

💀 COMMON MISTAKE: Opening hundreds of slots at once. Start with 6–8 slots per week. Scarcity is real. When leads see only a few slots available, they book faster than when they see a fully open calendar.

📅 Part 3: content_engine.py

Your content calendar. Plan posts, track status, enforce platform limits, push to Late MCP for multi-platform scheduling. Buffer charges $15–$99/month for this. You are doing it in one Python file.

Commands

create — Add a content item to the calendar

python scripts/content_engine.py create --platform instagram --type reel --title "3 signs your HVAC company needs AI" --due "2026-03-26 10:00" --status draft

calendar — Show the full content calendar

python scripts/content_engine.py calendar

python scripts/content_engine.py calendar --week "2026-03-24"

week-plan — Generate a suggested posting plan for the next 7 days

python scripts/content_engine.py week-plan

due — Show content due in the next N hours

python scripts/content_engine.py due --hours 24

templates — List saved content templates per platform

python scripts/content_engine.py templates --platform instagram

stats — Posting frequency and platform distribution

python scripts/content_engine.py stats

Platform Character Limits (Enforced at Create Time)

The engine rejects content that exceeds platform limits before it hits the scheduler:

• X/Twitter: 280 characters

• Threads: 500 characters

• Instagram: 2,200 characters

• LinkedIn: 3,000 characters

• TikTok: 4,000 characters

⚡ QUICK WIN: The create command validates character count against the platform limit at creation time, not at post time. You get an error immediately instead of discovering the limit violation at midnight when the scheduler tries to fire. Build the validation into the tool, not into your memory.

Late MCP Integration

The content engine stores items in Supabase. The scheduler (Lesson 4) polls the calendar for due content and fires posts_create via the Late MCP to push it live.

The integration call from the scheduler looks like this:

python scripts/content_engine.py due --hours 1 --json | python scripts/scheduler.py dispatch-content

This pipes due content into the scheduler's dispatch function, which calls Late MCP with the correct profile and character-validated body. The full pipeline is in Lesson 4.

🧠 KEY TAKEAWAY: Three engines, three replaced SaaS tools. But notice the pattern: each engine stores everything in Supabase, exports --json, and integrates with notify.py for real-time alerts. This is not three separate tools — it is three modules of one system. In Lesson 4, the scheduler becomes the conductor that wires them all together.
