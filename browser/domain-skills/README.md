# Domain Skills

Domain skills are site-specific browser memory. They capture durable map knowledge for web apps Bravo and the C-Suite use repeatedly.

Search these files before navigating a site with Browser Harness.

## Rule

Capture what the next agent needs before it starts. Do not capture secrets, cookies, tokens, private customer data, raw coordinates, or diary-style task narration.
