{{hook}}

Here's what I've learned building [specific thing]:

🧵👇

**Tweet 2-5 (Key Points — one per tweet):**
[Each tweet is self-contained — should make sense if read alone]

Format per tweet:
- Bold claim or number first
- 1-2 sentences of context
- Specific example or data point if possible

**Tweet 6 (Summary):**
TL;DR:

→ [Point 1]
→ [Point 2]
→ [Point 3]

**Tweet 7 (CTA):**

1. Follow @[handle] for more
2. Repost tweet 1
3. Reply with your experience

## Formatting Rules (X / Twitter)

- **HARD LIMIT:** 280 characters per tweet
- **First tweet determines thread performance** — spend 80% of effort here
- **Self-reply to create thread** — each tweet must work standalone
- **Use 🧵 emoji** to signal thread
- **Numbered format** (1/, 2/, 3/) works well for readability
- **No links in first tweet** — kills algorithmic distribution
- **Links go in last tweet or reply**
- **Images boost reach 2-3x** — attach when relevant
- **Post between 8-10am or 6-8pm ET** for maximum reach
- **Engage with replies within first hour** — signals the algorithm
- **Voice:** Direct, confident, no filler. Every word earns its place.
