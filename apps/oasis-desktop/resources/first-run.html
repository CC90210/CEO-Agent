Pair this machine to a workspace

In your dashboard, open Settings → Devices → Install Claude Code CLI bridge and copy the 9-character code that appears. Paste it below and we'll link this machine.

Generated in the dashboard's Devices panel. Single-use, 15-minute lifespan.

Your machine label (what your workspace shows in the device list) is set to your-machine. The bridge token lives in ~/.oasis/bridge_token with restricted permissions.

Connect a personal AI account (optional)

Skip this and your chat will use the workspace's shared AI key — totally fine for getting started. Connect your own to keep your usage on your account and unlock per-agent model choices.

The local bridge will route chat through your installed claude / codex / gemini binary automatically — no API key needed and your usage stays on your subscription. You can still add an API key below as a fallback if your CLI ever logs out.
Paste your provider API key. We validate against the provider before saving.

Your key is encrypted by your OS keychain via Electron's safeStorage and never leaves this machine. You can change it anytime from OASIS AI menu → Reset API key.
