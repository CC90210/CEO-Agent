# /retro — Weekly Retrospective

Load `skills/retro/SKILL.md` for the full retrospective protocol.

## Quick Steps

1. **Data Collection** — Git activity across all app repos (last 7 days), memory file changes, mistakes logged.

2. **Metric Calculation** — Commits, files changed, features shipped, bugs fixed, skills added, task completion rate.

3. **Scoring (0-10 scale)** — Shipping Velocity, Code Quality, Memory Health, Agent Coordination.

4. **Improvement Actions** — For every dimension scored below 7, generate 2 specific actions.

5. **Trend Analysis** — Compare against previous retros, identify recurring patterns.

6. **Memory Update** — Append patterns, mistakes, and retro summary to memory files.

7. Output the Weekly Retro Report.
